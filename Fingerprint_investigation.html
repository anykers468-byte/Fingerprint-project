How this simulation works

The activity compares the type, position and direction of manually placed minutiae. A stored feature is counted as matched when a corresponding comparison feature falls within its tolerance zone and has a sufficiently similar direction.

This is a simplified educational model. Real fingerprint recognition systems use more advanced image processing, feature extraction and matching techniques.
