# Fingerprint Sensor Project

## About the Project

This website is an educational project that explores how fingerprint sensors work and how they turn the unique patterns on our fingertips into information that a computer can understand.

Fingerprints may look like simple lines and curves, but the patterns contain small details that make them useful for identification. This project explains the science behind those patterns and introduces the technology used in capacitive fingerprint sensors.

 What Does the Website Include?

The website is divided into three main sections:

**1. Fingerprint Investigation**

This section introduces fingerprints and explains the three main pattern families: loops, whorls and arches. It also introduces minutiae, which are small fingerprint details such as ridge endings and bifurcations.

**2. How Fingerprint Sensors Work**

This section explains the basic science behind capacitors and how capacitive fingerprint sensors detect differences between fingerprint ridges and valleys. It also demonstrates how fingerprint information can be processed into a digital template.

**3. Interactive Activities**

The website includes activities that let visitors explore fingerprint details, compare fingerprint patterns and test their understanding through a short quiz.

## How Does the Code Work?

The website is built using **HTML, CSS and JavaScript**.

- **HTML** provides the structure and content of each section.
- **CSS** controls the layout, colours, fonts and overall appearance of the website.
- **JavaScript** makes the website interactive. It responds to user actions, updates diagrams, performs calculations and checks quiz answers.

Some of the diagrams are created using SVG, which allows fingerprint patterns and sensor illustrations to be drawn directly in the browser.

For example, the capacitor demonstration uses JavaScript to calculate capacitance using the formula:

`C = ε₀ εᵣ A / d`

Changing the slider changes the distance between the plates and updates the calculated capacitance. Other interactive demonstrations use JavaScript to move fingerprint patterns, highlight sensor electrodes and display different stages of fingerprint processing.

All calculations and interactive features run directly in the browser. The project does not require users to sign in, download software or provide an API key.

## Purpose

The main aim of this project is to make fingerprint sensor technology easier to understand through simple explanations, visual demonstrations and hands-on activities. It connects the science of fingerprints with the computing technology used to detect and process them.

**Note:** The diagrams and activities are simplified educational demonstrations. They are designed to explain the underlying concepts and are not real biometric scanning or authentication systems.
